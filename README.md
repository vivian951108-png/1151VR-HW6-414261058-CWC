# 1151VR-HW6-414261058-CWC
由方向鍵控制移動去接掉落的蘋果，接到紅色蘋果會加分，若接到黑色蘋果會扣分。
遊戲時會有遊戲音效。
第一關:時間限制40秒。紅黑蘋果掉落速度一致，接到紅色蘋果+2分、黑色蘋果-3分。時間結束後分數超過10分會通關。展示通關音效
若是分數有通過，會出現NEXT LEVEL的按鈕，點按進入下一關。
第二關:時間限制30秒。黑色蘋果數量變多，一次同時掉落兩顆，黑色蘋果掉落速度增加。接到紅色蘋果分數+1，接到黑色蘋果-3分。時間結束後分數超過5分會通關。
一樣通關會出現NEXT LEVEL按鈕。展示通關音效
第三關:時間限制25秒，黑色蘋果數量便更多，速度加快，同時掉落三顆蘋果。接到紅色蘋果分數+1，接到黑色蘋果-3分。時間結束後分數超過5分會通關。展示通關音效
